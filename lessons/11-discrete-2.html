離散技術（二）：深度、混合、模板

顏色不是唯一輸出。深度決定可見性，混合處理透明，模板做遮罩與特效。

深度測試

  • Z-buffer：每像素存深度，測試通過才寫。
  • 常見比較：LESS（近的蓋住遠的）。
  • 精度：非線性深度 → 近處精度高，遠處易 z-fighting。
Z-fighting。 共面或極近表面會閃爍。解法：polygon offset、提高精度、避免共面幾何。

Alpha 混合

C = α·Csrc + (1−α)·Cdst
  • 通常關閉深度寫入，但仍可深度測試。
  • 由遠到近繪製透明物；或 OIT（加權混合等）。
  • Premultiplied alpha 在合成時更穩。

模板緩衝

每像素整數，可做：

  • 鏡子反射遮罩
  • 描邊 / 輪廓
  • 門戶 / 窗戶裁剪

典型繪製順序

  1. 不透明（前到後可優化 early-Z）
  2. 天空盒 / 背景
  3. 透明（後到前）
  4. UI / 後製

檢查清單

  • 深度開啟？寫入策略？
  • 混合函數是否符合貼圖是否 premultiplied？
  • 模板 ref / mask / op 是否一致？
