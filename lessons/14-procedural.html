程序式方法（一）

用規則與雜訊「長出」內容，而不是手動雕刻每一個三角形。 好處：省工、可無限細節、參數可控。

程序式的價值

  • 內容管線可擴展（開世界、植被、城市）。
  • 可重現：同一種子 → 同一結果。
  • 可與藝術家參數（旋鈕）結合。

雜訊家族

類型特徵用途
Value noise格子隨機 + 插值入門、雲霧
Perlin / Simplex梯度導向，更自然地形、大理石
fBm多八度疊加細節層次
Worley最近特徵點距離細胞、熔岩
fBm(x) = Σi ampi · noise(freqi · x)

L-system（林氏系統）

並行重寫字串，再把字串解釋成筆畫指令（前進、轉角、推/ pop 狀態）。 經典用於植物、分形。 

axiom: F
rule:  F → F[+F]F[-F]F
// F 前進, +/- 轉角, [] 保存/恢復狀態

互動：fBm 雜訊

互動 分數布朗運動

應用場景

  • 地形高度場 + 貼圖混合權重
  • 植被散佈（泊松盤採樣）
  • 程序式材質（shader 內算 UV 樣式）
