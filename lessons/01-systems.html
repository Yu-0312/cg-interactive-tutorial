圖形系統與模型

電腦圖學把場景描述（相機、光源、幾何、材質）轉成像素。 一切現代 GPU 都圍繞可程式化管線運作。

你在做什麼

  • 輸入：三角形網格、紋理、矩陣、著色器。
  • 輸出：幀緩衝中的顏色（以及深度/模板）。
  • 目標：正確、快速、好看。

經典管線

應用層 → 幾何（頂點著色器）→ 裁剪 / 光柵化 → 像素著色器 → 合併 / 顯示
  1. 應用層：更新場景圖、動畫、送出 draw call。
  2. 頂點階段：模型視圖投影變換、法線變換、頂點屬性插值準備。
  3. 圖元組裝 + 裁剪：形成三角形，對視錐裁剪。
  4. 光柵化：決定覆蓋哪些像素，產生 fragment。
  5. 像素階段：貼圖、光照、測試（深度/模板/alpha）。
  6. 輸出合併：寫入幀緩衝，交換緩衝上屏。

兩種世界觀
