圖形程式設計（二）：著色器與動畫

著色器是在 GPU 上跑的小程式。頂點著色器處理每個頂點； 像素/片段著色器處理每個 fragment。

最小 GLSL

// vertex
attribute vec2 aPos;
void main() { gl_Position = vec4(aPos, 0.0, 1.0); }

// fragment
precision mediump float;
uniform float uTime;
void main() {
  vec2 uv = gl_FragCoord.xy / 300.0;
  gl_FragColor = vec4(uv, 0.5 + 0.5 * sin(uTime), 1.0);
}

為何時間要用 uniform

每個 fragment 都要看到同一個「現在幾點」，所以時間是 uniform； 位置則因頂點而異，是 attribute。
