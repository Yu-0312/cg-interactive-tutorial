圖形程式設計（一）

先用最簡單的 API 畫出東西。Canvas 2D 適合理解座標與像素； WebGL 適合理解緩衝與著色器。

Canvas 2D 最小範例

const c = document.getElementById("c");
const ctx = c.getContext("2d");
ctx.fillStyle = "#5b8cff";
ctx.beginPath();
ctx.moveTo(100, 50);
ctx.lineTo(50, 150);
ctx.lineTo(150, 150);
ctx.closePath();
ctx.fill();

WebGL 心智模型

  1. 建立 context 與著色器程式（頂點 + 像素）。
  2. 上傳頂點資料到 buffer，綁定 attribute。
  3. 設定 uniform（矩陣、顏色）。
  4. drawArrays / drawElements。
座標系。 WebGL NDC：x,y ∈ [−1,1]，原點在中心。Canvas 2D：原點在左上，y 向下。

為什麼從三角形開始

  • 任何曲面最終都三角化。
  • 平面內的仿射性質讓插值簡單。
  • GPU 原生吃三角形。

動手練習

  1. 把三角形改成用 gl.TRIANGLES 的三個頂點 RGB 插值。
  2. 加上 requestAnimationFrame 讓它旋轉。
  3. 記錄：viewport、clear color、座標翻轉為什麼需要。
