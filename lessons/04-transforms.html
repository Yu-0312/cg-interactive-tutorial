幾何物件與變換

頂點被矩陣變換。學會以正確順序組合 SRT 矩陣， 是早期圖學最高槓桿的技能。

齊次座標

點 $(x,y,z)$ 寫成 $(x,y,z,1)$。平移也能用矩陣乘法：

[x' y' z' w']ᵀ = M · [x y z 1]ᵀ
  • 位置 $w=1$，方向 $w=0$（忽略平移）。
  • 投影後除以 $w$（透視除法）。

核心矩陣（行向量約定依 API 而異）

T = translate · R = rotate · S = scale

常見物體變換：M = T · R · S（先在局部縮放，再旋轉，再移動）。

順序很重要

矩陣乘法不可交換。T*R ≠ R*T： 一個是繞原點旋轉再平移；另一個是平移後再繞原點旋轉。

3D 旋轉要點

  • 繞軸旋轉：X / Y / Z 軸矩陣；任意軸用羅德里格斯或四元數。
