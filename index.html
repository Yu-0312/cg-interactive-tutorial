建議學習路徑

沿管線由上而下，再進入建模工具。

  1. 看懂管線：應用層 → 幾何 → 光柵化 → 像素 → 顯示。
  2. 先寫小程式：清屏 / 用 WebGL 或 2D canvas 畫一個三角形。
  3. 掌握變換：縮放、旋轉、平移；模型 / 檢視 / 投影矩陣。
  4. 理解檢視：相機、透視 vs 正交、視錐體。
  5. 照亮表面：法線、環境/漫反射/高光、Blinn-Phong。
  6. 光柵化：掃描轉換、插值、深度測試、混合。
  7. 組裝場景：場景圖、階層姿態、程序式形狀、曲線。
